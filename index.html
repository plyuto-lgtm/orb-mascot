Orb Mascot Catalog

Use in an app

React

import { Orb } from 'orb-mascot/react';

<Orb body="bear" color="#1E6DF6" shade="gradient" size={160}
     ref={orb} onClick={() => orb.current.run('surprise')} />

Without React

import Mascot from 'orb-mascot';   // or <script src="mascot.js">

const m = new Mascot(svg, { body: 'bear', color: '#1E6DF6' });
m.start(); m.look(20, -5);

The swatches in this catalog are examples. color takes any hex value, or two hex values for a top-to-bottom gradient; the shader and eye contrast adapt to whatever you pass.

Package folder: packages/orb-mascot in the repository, with type definitions, a README covering every prop and ref method, and a no-build example. Open a body above for a snippet with its current settings.

One call for everything: run(id) returns a promise that resolves when the scenario ends, with .dur in ms. Body-specific acts are custom1, custom2 by position, so app code does not depend on a body's own names; the key in brackets is an alias. mascot.scenarios() lists all of them at runtime.

Size tokens

Pass a token or a number: size="md", size={32}. Tokens live on Mascot.SIZES.
